# MACE 单结构预优化接入补丁 1.0.0

适用：已经校验过的 exafs-compute-v1 0.1.0；阿里云 2 vCPU、约 4 GB 内存。
本补丁不安装 Python 包，不更换访问密钥，不启动、停止或重新创建 cloudflared。
安装会短暂重启本机 8001 端口上的计算接口。

## 安装

将整个压缩包上传到服务器并解压，进入包含 install.py 的目录：

    /opt/exafs-app/.venv/bin/python install.py --apply

安装前自动核对四个现有代码文件、独立 MACE 环境、模型 SHA256 和空闲队列。
版本不同或存在排队/运行任务时，停止覆盖。
可识别并保留本站 FDMNES 扩展的标准增量挂接；其他未知修改仍停止覆盖。
备份保存在原后台目录的 _mace_patch_backups/ 中。
启动或健康检查失败时，自动恢复原文件并尝试重新启动原接口。
失败时应保留终端输出和原 api.log 供排查；程序不输出接口密钥。

## 安装后验收

    /opt/exafs-app/.venv/bin/python check_mace.py --input /opt/mace-app/inputs/POSCAR --steps 10

验收会创建两个保留输入和输出的服务器任务：结构解析与 MACE 预优化。
它验证本机 HTTP、单任务队列、独立 MACE 进程、固定设置以及结果下载。
原路径输入保持不变。未达到力阈值的结果仍输出，明确标记未收敛。
此检查不验证网页 HTTPS 隧道，也不验证 MACE 的物理精度。

## 网页使用

打开原网站，进入服务器计算，上传并解析结构。
在结构上传区下方的“MACE 结构预优化”中检查接入和固定原子数。
默认：100 步，最大可移动原子力 0.05 eV/Å，单步最大位移 0.05 Å。
可先设 10 步验证网页往返；随后按实际需要提交更长的任务。

同一队列依次运行结构解析、FEFF、Larch 和 MACE。
MACE：固定晶胞，保留 FixAtoms/FixScaled，1 CPU 线程，最多 200 原子、300 步。
单任务墙钟时间上限 20 分钟，监督进程每 0.25 秒检查一次；
超过约 2304 MiB 常驻内存时终止任务。瞬时峰值与操作系统 OOM 仍可能先发生。
取消排队任务后不会运行；运行中的取消通过监督进程终止子进程。
服务重启后，原运行任务标记中断；排队任务保留。
另有命令行 MACE 占用 /opt/mace-app/mace.lock 时，本任务失败并提示稍后重提。

任务记录保留步数、最大力、收敛状态、轨迹、参数、模型校验值和运行日志。
优化完成可下载 VASP、EXTXYZ、CIF（有有效三维晶胞时）、ASE 轨迹及结果 JSON。
CIF 不保存固定约束；继续优化应使用 VASP 或 ASE 轨迹。
点击“选用此结构并重新解析”才会把预优化结果设为新的结构任务。
它清空当前 FEFF/拟合选择，原有任务不删除；吸收原子需要重新选择。

## 已完成验证与限制

用户服务器此前已完成真实 MACE-MP-0b2-small 的 148 原子、10 步 CLI 测试：
约 2.07 秒/步、867 MiB 峰值内存，98 个固定原子和晶胞未移动。
该 CLI 测试发生在本接入补丁安装之前，不能替代本补丁的接口验收。

本地回归测试覆盖鉴权、原文件保留、参数边界、约束、取消、单队列及任务恢复。
工作进程的文件/约束测试使用 ASE EMT 作为测试替身，不是 MACE 精度测试。
本地未重新执行真实 MACE；用户服务器的接口往返与网页真实计算仍待安装后验收。

输出是候选预优化结构。低能量、较小受力或优化收敛均不能独立证明实验结构正确。
本模型的训练势能面不等同于用户的 VASP 泛函、U、磁性、溶剂或色散设置。
不要把模型能量与 VASP 能量直接混用。实际 Pd 局部配位还需 EXAFS/DFT 验证。
